# Shortcuts

The same as FL Studio, and every one of them can be remapped in Settings.

| Key | Action |
|---|---|
| Ctrl+K | Command palette: every action in a few keystrokes |
| Space | Play / stop (back to the start marker) |
| F5 · F6 · F7 · F8 · F9 | Playlist · Channel Rack · Piano roll · Sample Lab · Mixer |
| Tab | Next view |
| L | Pattern / song mode |
| R | Arm recording |
| T | Tap tempo |
| F4 | New pattern |
| + / − | Next / previous pattern |
| Alt+F8 · Ctrl+F | Browser · search |
| Ctrl+T | Computer keyboard as a piano |
| Ctrl+M | Metronome |
| Ctrl+Z · Ctrl+Y | Undo · redo |
| Ctrl+N · Ctrl+S · Ctrl+Shift+S · Ctrl+O | New · save · save as · open |
| Ctrl+R | Export |
| Ctrl+C · Ctrl+V · Ctrl+B | Copy · paste · duplicate (notes, clips, time selection) |
| Ctrl+Q | Quantize |
| Ctrl+G | Group mixer tracks into a bus |
| Ctrl+Shift+C | Capture the last phrase you played |
| Ctrl+= · Ctrl+− · Ctrl+0 | Interface size |
| Ctrl+Shift+F | Maximize the view (browser and devices hidden), again to restore; double-clicking a view tab does it too |
| Ctrl+wheel | Zoom in time (piano roll, playlist) |
| Alt+wheel | Key height in the piano roll (or Ctrl+wheel on its keyboard), track height in the playlist |
| Hold right-click | Erase what you sweep over (steps, notes, clips) |
| Right-click a control | Automate, link to a MIDI controller, reset |

## Layout

Every border between areas can be dragged: the browser, the device panel, the
lanes under the piano roll, the playlist's pattern list and the Channel Rack's
names. Hover a border to see its grip, drag it, double-click it for the default
size. Drag the browser, the device panel, the piano roll lanes or the pattern
list to the edge to fold them; a small tab stays to open them again. Sizes and
zooms are saved with your settings, and each view keeps its own device panel
height. On a short screen the piano roll, mixer, session and Sample Lab start
with the device panel shrunk to its header: drag it up to see the devices.
## Audio editor (Sample Lab, Edit mode)

Like Edison; while the editor is shown, these keys go to it first.

| Key | Action |
|---|---|
| Space | Play the selection (or from the cursor) |
| L | Loop the selection while playing |
| R | Record the microphone into the editor |
| Ctrl+X · Ctrl+C · Ctrl+V | Cut · copy · paste (replaces the selection, or goes in at the cursor) |
| Del · Ctrl+Del | Delete the selection · crop to it |
| Ctrl+I | Insert silence |
| Ctrl+N · Ctrl+R | Normalize · reverse |
| Ctrl+Shift+I · Ctrl+Shift+O | Fade in · fade out |
| Ctrl+A | Select everything |
| M · Shift+M | Add a marker · make a region of the selection |
| Z · Home | Zoom to the selection · see the whole sound |
| Shift+S | Waveform or spectrogram |
| Ctrl+Z · Ctrl+Y | Undo · redo in the editor |
| Wheel · Shift+wheel | Zoom · scroll |
| Alt while dragging | No snapping |
